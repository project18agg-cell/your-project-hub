# Enterprise Zoho-style public site redesign

## Goal
Apply the selected enterprise Zoho-inspired direction across Upcurv’s public website while retaining the existing red-and-white identity, content, links, pricing, forms, and SEO.

## What will change
- Establish a consistent public-page system: crisp white surfaces, warm neutral section bands, Upcurv red accents, compact enterprise navigation, thin borders, restrained shadows, and stronger information hierarchy.
- Redesign the homepage around the selected composition: centered problem-first introduction, clear actions, structured ecosystem/product cards, proof-oriented strips, and practical software-interface details.
- Restyle shared navigation and footer so every public page carries the same compact enterprise language.
- Bring Custom SaaS, Pricing, use-case pages, Upcurv Halls, Blog, About, Careers, and legal pages into the same system without changing their wording or behavior.
- Refine mobile spacing, typography, navigation, buttons, grids, comparison controls, and forms so content remains readable without truncation or overlap.
- Preserve all existing SEO metadata, structured data, public URLs, lead capture, pricing, and external product destinations.

## Technical details
- Update semantic design tokens and reusable public layout classes rather than hardcoding page-level colors.
- Keep authenticated admin pages functionally and visually separate from this public-site redesign.
- Reuse existing shared Button and form controls; only introduce small shared public layout components where repetition justifies them.
- Verify key public pages at phone and desktop widths, then check the current build diagnostics and targeted tests.
